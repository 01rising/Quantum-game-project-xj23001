# Quantum Aeroplane Chess: Crisis Skies

## Project Overview

Quantum Aeroplane Chess: Crisis Skies is a strategy board game made in Godot. The game reimagines traditional aeroplane chess as a crisis-response mission where players coordinate relief teams, deliver aid, and stabilize disaster zones before global instability becomes uncontrollable.

The project combines board-game movement with quantum-inspired mechanics such as probability, prediction, amplification, and entanglement.

## Game Theme

In a near-future world affected by climate disasters and unstable infrastructure, response teams must travel across a crisis map and deliver the correct aid to affected regions.

Players must manage movement, aid loadouts, crisis severity, and global instability while using quantum tools to improve their chances.

## Main Features

- 2–4 player support
- Turn-based board movement
- Crisis tiles with different disaster types
- Per-player aid loadouts
- Aid selection menu
- Crisis escalation and clearing
- Global instability system
- Quantum movement and special actions
- Event card alerts
- Player/team identity cards
- Visual crisis icons
- Animated player sprites
- Sound effects
- Opening mission briefing
- Save and load system
- Final mission outcome screen

## Crisis and Aid System

Each crisis requires a matching aid type:

| Crisis Type | Required Aid |
|---|---|
| Flood | Water Rescue |
| Wildfire | Fire Response |
| Medical | Medical Supplies |
| Infrastructure | Repair Team |
| Food Shortage | Food Aid |

Players can change their current aid loadout during the game, but changing aid costs a turn. This creates a tactical choice between moving quickly and preparing the correct response.

## Quantum Mechanics

The game includes several quantum-inspired abilities:

- Quantum movement
- Oracle prediction
- Amplification
- Entanglement
- Stabilization actions

These mechanics add uncertainty, risk, and strategic decision-making to the board-game structure.

## Controls

Use the on-screen buttons to:

- Deploy / move
- Change aid
- Use quantum tools
- Stabilize crises
- Save the game
- Return to the main menu

## How to Run

1. Open Godot 4.
2. Import the project folder.
3. Open `project.godot`.
4. Run the project.

The main scene is configured through the Godot project settings.
